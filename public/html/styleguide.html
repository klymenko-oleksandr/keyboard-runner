Briefing

The "Race briefing" panel: what the game is and how to play, in four numbered steps.

Race briefing

Up to 5 drivers, one text, 60 seconds.

  1. 1Create a room or join one on the grid.
  2. 2Press Ready. When every driver is ready, a 5-second countdown starts and the start lights come on.
  3. 3When the lights go out, type the text exactly. A wrong key keeps you in place.
  4. 4First across the line wins. After 60 seconds, the most characters typed wins.

Desktop only: you need a physical keyboard.

Commentary

The commentator's booth next to the race panel: aside.commentary (pit, radius-md) with a header (mic, LIVE dot, name, four talking bars) and ol.commentary-feed. Each li.comment.comment-<type> has a tag and a text; the colour of the left line follows the type (kerb-red start / finish straight, finish-green finish, yellow results). .is-on-air lights the LIVE dot, .is-speaking animates the bars for a moment after each comment, .is-latest highlights the newest one.
